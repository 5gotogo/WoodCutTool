How the difference range works

Observed gap = |A − B|. With uncertainty ±u on each reading, the possible gap is max(0, gap − 2u) through gap + 2u. The whole range must fit inside your limit for a “within” reading state. If it crosses the limit, the state is borderline; if the lower bound exceeds the limit, it is outside. This is a bounded comparison, not a statistical confidence interval.

What the reference diagonal means

Reference diagonal = √(width² + height²). A 600 × 800 mm intended rectangle has a 1,000 mm diagonal. This comparison does not validate the actual side dimensions or plane. Equal diagonals alone can occur in a tapered shape; inspect sides and corners as well.

What completes a review

A review is complete only when the readings are within your chosen tolerance and all four physical checks are confirmed. Any relevant adjustment needs another check. The tool gives no universal tolerance, clamp force or correction distance; use the project requirements and physical trial fit.

How to preserve the records

Save separate snapshots before and after adjustments. CSV contains millimeter values, reading bounds, status and check states. JSON preserves the draft and records for reviewed replacement on import. Unreadable storage is preserved, and storage failures are reported while exports remain available. Clearing browser data can remove local records.
