# Blog first-render improvement — 2026-09-17

The supplied Cloudflare screenshot shows LCP P75 4,284 ms, P90 12,312 ms, and P99 23,484 ms. Blog has the largest displayed sample count (29); these figures do not establish a single cause for the entire traffic population.

The live Blog HTML was checked and uses the same external editorial stylesheet and runtimes as the original checkout. A single live curl observation had TTFB 1.292 s and total 3.413 s; it is not a regional or percentile baseline.

## Change

The post-generation step now compiles only Blog-index selectors from the authored styles and runtime tokens, then embeds the complete scoped stylesheet in the document. CSS falls from 62,754 to 39,793 uncompressed bytes and no external stylesheet request blocks Blog rendering. Auxiliary Blog scripts use low fetch priority. Navigation, archive links, content, and language support remain available.

Inlining trades a separately cacheable stylesheet for one fewer cold-load dependency. Compressed HTML grows from 15,081 to 24,307 bytes; the original external CSS was another 13,795 compressed bytes. Only Blog index uses this inline policy. Generated CSS is excluded from selector discovery so repeat builds can remove obsolete rules.

The dev server defaults to loopback for local validation; `npm run dev:lan` explicitly keeps LAN access. The performance harness brings its tab to the foreground and rejects missing paint measurements instead of reporting zero as an improvement.
