# App 页面 LCP 优化记录 — 2026-09-04

## 结论

本地冷缓存、gzip、移动端限速对照中，`/apps/` 三轮 LCP 中位数由 **884 ms 降至 564 ms（约 36%）**。LCP 元素始终为首屏 `p.lead`，面积 90,678，CLS 均为 0；没有通过隐藏、缩短或移动首屏内容改变指标。

这是实验结果，尚未部署，也不代表 Cloudflare 真实用户 P75 已达到该数值。截图的过去 24 小时记录为：LCP 好 75%、需要改善 11%、差 14%，P75 2,436 ms、P90 5,108 ms、P99 9,772 ms。截图没有逐次访问的 TTFB、资源瀑布或设备信息，不能据此判定每个慢访问的原因。

## 改动

- 160 个 `/apps/` 页面使用从 `assets/styles.css` 编译的 `assets/apps.css`。原 CSS 231,001 字节，精简版 68,088 字节。
- 应用目录、详情、对比与静态落地页改用已有的 1,800 字节 `content-page.js`；默认英文页面不再下载 297,694 字节的 `app.js`。选语言或恢复已保存的语言时按需加载。
- 编译保留所有 App HTML 和运行脚本引用的类，包括菜单、移动端横向滚动、语言与动态状态；通过 Lightning CSS 解析和精简，不按单一视口裁剪。
- `apply:nav-cta` 自动生成样式并更新引用，完整构建也走此步骤。新增 CSS 80 KB 体积上限、编译产物一致性、全部 App 页样式与脚本引用检查。
- 正文、链接、结构化数据保持原样，Sitemap 和 lastmod 没有变化。

## gzip 实验

Chrome headless，390 × 844 CSS 像素，CPU 4 倍减速，网络延迟参数 150 ms，下载 200,000 B/s，上传 100,000 B/s，浏览器缓存关闭。本地服务器压缩 HTML/CSS/JS，旧版与新版交替运行三轮。

| LCP | 第 1 轮 | 第 2 轮 | 第 3 轮 | 中位数 |
| --- | ---: | ---: | ---: | ---: |
| 修改前 | 1,240 ms | 876 ms | 884 ms | 884 ms |
| 修改后 | 564 ms | 548 ms | 568 ms | 564 ms |

| CSS/JS gzip 正文字节数 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 样式表 | 38,796 | 14,759 |
| 页面运行脚本 | 73,804 | 643 |
| 共享导航脚本 | 13,590 | 13,590 |
| 转化脚本 | 2,568 | 2,568 |
| 合计 | 128,758 | 31,560 |

主要 CSS/JS 压缩体积下降约 75.5%。未压缩本地预览的单轮测试为 3,696 → 1,376 ms，仅作定位参考。线上 CDN 压缩、连接建立、缓存、地区和设备不同，不能用上述时间替代真实用户数据。

## 验证

- 应用目录、Casework、TileFit、CutList、QuiltFit、对比目录和一个对比详情页，在 360/390/430/1440 px 共 28 组新旧样式对照中，正常状态及打开菜单后的 DOM 几何与所检查的计算样式一致，未见横向溢出。
- 默认英文不请求 `app.js`；首次切换中文仅请求一次；阿拉伯文 RTL、刷新恢复、切回英文均通过。
- 浏览器布局对照阻断外部图片请求以减少网络噪声，因此不构成对 Apple 图片服务可用性的验证。
- `npm run check` 通过：2,470 个 HTML、2,368 个 Sitemap URL，以及现有计算器、项目、SEO、架构、转化与性能检查。
- 比较 160 个修改页面的内容签名、检查 JSON-LD 与页面差异；性能资源引用之外无内容变更。`git diff --check` 通过。

## 维护与上线后复核

先执行 `npm ci`。编辑源样式或重新生成 App 页后执行 `npm run apply:nav-cta`，再运行 `npm run check`。不要直接编辑 `assets/apps.css`。

部署后，按部署时间划分 Cloudflare 数据，分别看 `/apps/`、其他 App 页、设备和地区的 LCP P75/P90 与样本量；如慢访问仍集中在 TTFB，则继续检查该地区网络与 CDN 响应。全站截图不足以证明这轮改动解决了所有长尾。

参考：[Google LCP 优化说明](https://web.dev/articles/optimize-lcp)、[Lightning CSS 精简与 unusedSymbols](https://lightningcss.dev/minification.html)。
