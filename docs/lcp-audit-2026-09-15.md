# Wood and Blog LCP Follow-up — 2026-09-15

## Scope

This follow-up targets the route families visible in the Cloudflare Web Analytics screenshot: generated `/wood/*` species pages and image-led `/blog/*` articles. The dashboard window contained 35 page views, so individual orange or red URLs were treated as low-sample field signals rather than stable route-level regressions.

## Changes

- Added a generated `wood.css` profile for 201 Wood pages instead of serving the broader `content.css` bundle.
- Added a generated `blog-article.css` profile for 1,069 Blog article routes instead of serving the Blog index and Compare rules in `editorial.css`.
- Marked translation, conversion, and supporting article-image requests as low priority on the affected routes. The hero image remains eager, preloaded, and high priority.
- Recompressed the 12 responsive woodworking image pairs with visual review. Their combined size fell from 977,454 to 692,810 bytes, a 29.1% reduction.
- Added one-hour browser caching with stale-while-revalidate for shared CSS and lightweight JavaScript assets.
- Extended the performance harness with `--dpr` / `WCT_PERF_DPR` so high-density mobile image selection is testable.
- Added stylesheet freshness, route assignment, image-priority, image-budget, and cache-policy regression guards.

## Local measurements

The controlled profile used the local gzip preview, a 390 × 844 viewport, cold cache, 4× CPU throttling, 150 ms latency, and 200 KB/s download throughput. Each standard-DPR result is the median across the five screenshot-representative routes with three runs per route.

| Route family | Before LCP | After LCP | Change | Before transfer | After transfer | Change |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Wood species | 608 ms | 492 ms | -19.1% | 39,754 B | 32,037 B | -19.4% |
| Blog articles | 596 ms | 564 ms | -5.4% | 71,905 B | 65,845 B | -8.4% |

At 3× DPR, the five Blog routes completed with LCP between 652 and 812 ms across two runs per route after the 960 px image recompression. All standard-DPR samples reported CLS 0 and no horizontal overflow.
