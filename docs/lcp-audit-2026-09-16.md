# Core Web Vitals Follow-up — 2026-09-16

## Field signal

The supplied Cloudflare screenshots show 81% good / 10% needs improvement / 9% poor LCP over 21 days (890 page views), and 73% / 12% / 15% over the latest 24 hours (59 page views). Several red routes in the short window have only one or two observations, so they are treated as investigation leads rather than stable route-level regressions.

The short-window set spans the homepage, calculators, Troubleshooting, Wood, Legal, Blog, and Learn. Local checks therefore kept those families in the same regression matrix instead of optimizing a single reported URL.

## Changes

- Replaced the homepage's eager full calculator runtime with a generated 5.9 KB planner runtime. The full translation/calculator bundle now loads only when a visitor selects a non-English language.
- Kept the homepage planner fully interactive and added a duplicate-binding guard for the later language-runtime handoff.
- Removed the 36 KB construction-calculator runtime from six static Learn topic hubs.
- Added responsive 800/1200 px hero candidates and matching preloads to all 23 generated construction calculators.
- Deferred non-critical mobile reading-progress, rail, and back-to-top setup until browser idle time.
- Deferred mega-menu HTML assembly until a menu is actually requested.
- Added build-time guards for the new runtime assignments, responsive hero contract, cache policy, and static hub behavior.
