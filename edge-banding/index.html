How finished sizes become saw blanks

Saw length = finished length − left/right added thickness + left/right pre-milling. The same rule applies to width with top/bottom edges. Without pre-milling, a 720 × 400 mm door with 2 mm edging on all sides needs a 716 × 396 mm blank. A 600 × 300 mm shelf banded on the top edge in 1 mm tape needs a 600 × 299 mm blank. The added thickness should reflect your finished process, including the measured effect of bonding and trimming.

What the purchase estimate includes

Each banded edge is one strip per physical part. We use the larger saw or finished envelope along that edge, add end allowance twice, then add your waste percentage separately for each profile. Tape must be wide enough for the panel plus the selected face overhang. Roll counts are lower bounds from total length: a set of long strips may need more rolls because remainders cannot be joined into one continuous strip. The planner does not optimize strips across rolls or specify the banding sequence.

Transfer the correct blanks to a layout

The sheet-layout action sends saw sizes, quantity, panel material, measured thickness, grain locks, sheet dimensions, kerf and stock trim to the plywood calculator. That calculator shows an incoming-list review before applying it. Materials of different names or thicknesses are kept in separate stock groups. Edging codes remain in this planner and the CSV; the nesting tool only receives rectangles. Kerf is handled between adjacent parts, not added to the blank dimensions here.

Check the process before release

Test a representative part, measure its finished outside size, and compare it with the drawing. Confirm reference face, grain, edge identities, corner treatment, adhesive and machine settings. The model does not add hinge drilling, joinery, door gaps, face laminates, hardware clearances, structural checks or curved edging. Product nominal thickness and a green width check do not certify the final fit. If the physical test differs, update the profile and regenerate the list.

Save and move your project

Inputs save in local browser storage when available. JSON exports preserve editable dimensions, units, profiles and allowances; importing presents an explicit replacement review. Cut-list CSV includes both saw and finished dimensions, quantity and edge codes. The edging CSV records allowances and minimum rolls by length. If storage fails, you can continue in the current tab and export a backup. Nothing in this feature requires an account, file upload or remote project storage.
