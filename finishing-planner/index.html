THE CALCULATION, OPEN TO REVIEW

Surface area.
Coats. Coverage. Packages.

This planner estimates finish quantity for rectangular panels. It connects the geometry to the product schedule so a purchase can be checked before work starts.

Built by WoodCutTool editorial team · Updated 2026-10-08.

How the selected area is counted

Each face = length × width. Each top/bottom edge = length × thickness. Each left/right edge = width × thickness. Sum selected surfaces and multiply by quantity. Four 600 × 300 × 18 mm shelves with two faces and one length edge selected have 1.4832 m² of coated surface for one coat.

How the product quantity is calculated

Base volume = selected area × coats ÷ coverage per coat. Add your extra percentage, deduct usable stock, and round the remaining requirement up to whole packages. A and B are calculated independently. Extra allowance is an added percentage of volume; it is not spray-transfer efficiency.

What to verify before using the list

Use the exact product instructions and a representative test panel. The planner does not specify finish compatibility, drying, cure, ventilation or assembly readiness. It does not model curves, holes, routed profiles or partial masking. Package counts use one editable size per product. Check the surface schedule and label before buying.

Saving and restoring your project

Valid changes save in this browser when storage is available. Export JSON to keep an editable backup and CSV for the purchase review. Imports are validated and require a replacement review. Browser data does not sync between devices. Project dimensions and product inputs are not uploaded.
