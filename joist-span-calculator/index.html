FAQ

Common Joist Span Planning Tool questions

Why does the tool not give a safe joist span?

A safe span depends on code tables and project-specific variables that a simple generic calculator cannot certify.

What information do I need for a joist span table?

Usually species, grade, size, spacing, design load, support condition, and the locally adopted code edition.
