## 采集协议

- ChatGPT Search、Gemini、Claude 联网搜索、Perplexity 各跑一轮。每题单独开新对话，提交原句，完整保存回答及展开的来源 URL。产品体验与官方 API 作为不同测试模式记录。平台未开放、登录过期、额度不足、搜索工具未启用均记录缺测原因。
- 每题记录实际执行时间、模型／版本、搜索模式、地区、品牌名、目标 App、域名引用、具体 URL、竞争产品、推荐理由、App Store URL、事实错误及核对依据。明显波动时择日用独立会话做第二次观察。周趋势比较同一平台、同一题库、同一模式下可配对的题，并披露样本数。
- “提及品牌”要求回答明确出现 WoodCutTool。“提及 App”要求可从文字或链接归属到目标产品。“引用”要求回答或展开的来源列表直接挂出 woodcuttool.com 的 URL。“推荐”要求把目标产品明确列作适配的选择。App Store 链接要求目标 App 的 Apple ID 匹配。
- 比率分母为该平台、App 下实际有完整结果的有效回答数。缺测留空。首轮公共网页检索仅作发现信号。按北京时间记录审计日，后台数据周窗口依来源时区标注。
