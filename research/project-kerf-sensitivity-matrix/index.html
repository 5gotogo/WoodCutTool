What the matrix shows

1 of 36 projects changed estimated sheet count between the zero-kerf counterfactual and a 1/4 inch spacing assumption with rotation allowed. The other projects retained the same count, although their available free rectangles and cutting options still changed.

A sheet-count change is a threshold result, not a universal blade recommendation. Actual kerf depends on the blade, tooth geometry, runout, machine, material, and measurement method.

Method and safe use

  1. Use the same named parts list in every run.
  2. Hold the nominal sheet at 96 × 48 inches.
  3. Run seven declared spacing values from 0 to 1/4 inch.
  4. Repeat with rotation allowed and orientation locked.

Zero kerf is a mathematical baseline and cannot represent a real saw cut. The heuristic does not model a shop cutting sequence, shared cuts, edge trim, defects, grain matching, joinery, or replacement parts, and it does not prove a global optimum. Measure the actual blade with a test cut before using the plywood cut calculator.
