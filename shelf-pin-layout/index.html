BEFORE THE FIRST HOLE

One reference. Four matching supports.

Start with finished parts

Mark inside faces, finished fronts and the bottom datum on both equal-size side panels. Measure actual thickness. Changing an edge after drilling can move the reference. This planner models one left/right pair; shared dividers drilled from both faces need a separate review.

Reserve the occupied space

Record hinge, groove, fixing and support envelopes as measured height bands. The planner removes complete four-hole levels without shifting the original grid. A remaining level describes hole geometry; check the real shelf and door through their working travel.

Test the whole setup

Prove the bit, stop and actual pin in matching material. Compare low and high centers on the test pair, then install four supports and a shelf. A geometric pass cannot measure hole quality, case twist, shelf sag, support capacity or anchoring.

METHOD / VERSION 1

Read the model before transferring the pattern.

For each nonnegative whole index n, the center height is origin + n × pitch. Accepted centers keep the full hole circle inside the entered top and bottom rim clearances. A keep-out removes a level if the circle touches or crosses its height interval. Every remaining level has two rows on each of two equal panels.

Front X equals the front setback; rear X equals panel depth minus rear setback. Coordinates in the CSV always use the panel’s own finished front and bottom. The right SVG panel is mirrored horizontally for a labeled inside-face bench view. Drill-tip reserve equals measured thickness minus entered maximum penetration. The model rejects overlapping rows, invalid dimensions, an insufficient reserve and a pattern with no complete remaining level.

All lengths use millimeters. Use the exact documented pitch: 1¼ inch converts to 31.75 mm and must not silently replace a 32 mm series. Kreg’s product documentation supports the example 32 mm pitch, 37 mm fence reference and matching pin/bit choice. True Position Tools provides an additional jig-specific reference sequence. Grid-phase arithmetic, mirrored display, full-width keep-outs and entered skin reserves are this planner’s stated model.
