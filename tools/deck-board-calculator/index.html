How the estimate works

Use the number as a planning starting point.

Deck width divided by effective board width gives the number of board courses. Courses multiplied by deck length gives linear footage; stock-board count uses your selected purchase length.

Measure first

Measure finished dimensions, actual stock, openings, and site constraints before ordering material.

Check the result

The estimate assumes straight, parallel board courses. Diagonal boards, picture framing, seams, butt-joint layout, board-length availability, and defects can increase material use.

FAQ

Common Deck Board Calculator questions

How many deck boards do I need?

It depends on deck width, board face width, gap, course direction, and available stock length. This tool converts those inputs into a starting count.

Does this include diagonal decking?

No. Add more waste and use a project-specific layout for diagonal or patterned boards.
