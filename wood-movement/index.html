AN ESTIMATE YOU CAN TRACE

The coefficient.
The scenario.
The drawing.

Width change = measured width × coefficient × MC percentage-point change. Calculate each endpoint from the same current width; subtract dry width from wet width for the seasonal swing.

Wet clearance = fixed opening − wet width. Reserve balance = wet clearance − your required total reserve. Center and edge references describe assumed displacement, leaving attachment geometry for the actual drawing review.

What does this wood movement calculator estimate?

Approximate unrestrained cross-grain width changes of the listed solid woods over an entered 6–14% wood moisture content range, using USDA Wood Handbook Table 13–5 and Equation 13–3.

Can I enter room relative humidity?

No. Enter wood moisture content, not air relative humidity. The tool does not predict a service range or an acclimation time.

Does the result specify an attachment or slot?

No. The opening is assumed fixed and the reserve is user supplied. Edge travel is displacement under an entered locating-reference assumption; it is not a slot length or construction approval.

Where is the project saved?

Valid drafts stay in this browser when local storage is available. Export JSON to restore the editable draft and CSV to retain a review. Project inputs are not uploaded.

How should I read “compare both”?

These are separate radial and tangential models. They do not establish statistical uncertainty bounds, the actual ring angle or a guaranteed movement range. The planner does not model warping, mixed-species glue-ups or restrained stresses.
